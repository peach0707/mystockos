# UI/日本語表示の再レビュー

主要Visual Source of Truth：提出済み「株ゴリラ_Work提出用_設計書＋画面案.pdf」先頭の8画面案。色の符号は最新指示を優先し、利益＝赤、損失＝緑。

## 対応
- ホーム：市場環境→今日の方針→今強いテーマ→初動検知→保有銘柄→重要ニュース。基準日と注意事項は保持し、詳細を開閉。
- テーマ：テーマ名・強さ・勢い・過熱度のコンパクトな行。先行スコア/失速リスクは「—」。タップで構成/根拠を開閉。少数構成は分野別表示を維持し、順位付けしない。
- 銘柄：銘柄/価格/所属テーマ/そのテーマの指標を一覧表示。投資根拠・買い条件のフォームは行を開いて確認。
- ニュース：余白を縮小、日本語ラベル。自動収集は引き続き未接続。
- 保有：総資産、損益、配分ドーナツ、各機能ショートカット。配分は登録データのみで描画。
- カレンダー：全幅7列、日付/損益/率、未評価は「—」。大きい金額は万円表記、詳細は円単位。月間見出しを設け、既存の日別結果を表示用に集約。月境界の評価がない場合は正確な月間損益を推定せずデータ不足、日別損益は引き続き直前の有効評価と比較。入出金がある場合の月間率は未算出。
- 年初来：資産増減/運用損益を上部に表示。軸・凡例付き2系列グラフ。比較用の線色は青/紫、金額の正負色とは区別。記録点間を線で結び、日々の値を生成しない。
- 配当・設定：小さめのカード、余白/フォームを統一。個人台帳や保存キーは維持。
- ナビ：統一した線アイコン＋日本語ラベル。safe-area上下左右を保持。フォーム文字16px、操作ボタン44px以上。
- 日本語マッピングは assets/js/display-ja.js に独立。全29テーマ、分野、判定状態・根拠の表示を変換。元のテーマ名・識別子・CSVは不変。

## 未実装部分を画面案のダミー値で埋めない

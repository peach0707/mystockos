# 証券会社別の保有登録と平均取得単価（2026-09-22）

## 変更内容

- 楽天証券・moomoo証券など、同じ銘柄の複数登録を許可する。
- 各登録に一意のIDと任意の証券会社名を保存し、編集・削除は選んだ登録分だけに適用する。
- 保有一覧・銘柄数・評価額・配分は銘柄ごとに集約する。合計を別途保存せず、元の登録から都度計算する。
- 平均取得単価 = Σ（株数 × 取得単価）÷ Σ株数。同じ通貨同士で計算し、計算途中では丸めない。
- 100株 × 100ドルと50株 × 130ドルなら、150株・平均110ドルとなる。
- 取得通貨が混在するときは平均取得単価を通貨別に表示する。円評価の取得金額は通貨別に換算して合計し、為替未取得なら推測しない。
- 「この銘柄を追加」から銘柄を選択済みで開ける。元の株数は複写しない。
- 保有判断・投資根拠・利用履歴は引き続き銘柄単位。追加時に既存の判断・根拠をフォームへ引き継ぐ。

## 既存データ

- `mystockos.private.v6`を継続使用する。既存のID・証券会社名なしの保有をそのまま読み込み、未指定と表示する。
- 既存保有にIDを付与するのはその登録分を編集するときのみ。読み込み時に数値や元データを書き換えない。
- 未指定の保有を証券会社名だけ変更しても、保有評価の比較基準は変わらない。数量・取得金額が変われば従来同様に比較を再開する。
- バックアップに全登録分を保存し、重複ID・識別不能な旧形式の重複・不正数値を拒否する。
- 公開先・保存キーを変えないこと。利用者の端末データを公開リポジトリに含めない。

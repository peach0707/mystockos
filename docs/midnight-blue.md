# ミッドナイトブルー / 2026-10-02

ユーザー指定の参考画像から、黒に近いネイビー、細い青い枠、大きな白い数字、青いチャートを採用。参考は外観のみで、不動産の機能や画像は取り込まない。

`assets/noir.css` が最後に読み込まれる共通の外観レイヤー。ホーム、テーマ、銘柄、ニュース、保有、カレンダー、設定、入力フォームまで同じ色を使用する。

- 背景 `#050a12`、パネル `#0c1523`、本文 `#edf4ff`、補足 `#9baec5`、アクセント `#62beff`。
- 増加はコーラル、減少はミントを維持。数字の符号や状態の文章でも意味を区別する。
- 実データの折れ線に青い面を追加。記録がない部分や保有変更をまたぐ区間をつなげない。
- 入力は16px以上を維持。iPhoneの入力時拡大を防ぐ。縮小モーション設定とキーボードフォーカスを維持。
- PWAのid、scope、start_url、個人データの保存キーは変更しない。
- 数量、平均取得単価、評価額、テーマ判定の計算変更なし。

既存のChromium / WebKit操作テストで320〜1024pxを検証し、設定・保有入力フォームの画面も保存する。

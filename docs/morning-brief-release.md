# 朝のまとめへの改修（2026-10-03）

既存の株ゴリラを「自分の持ち株の重要な変化を、日本語で毎朝1分で確認する」ための画面構成へ変更。

## 変更

- ホームは登録資産・増減、前回取得からの重要な変化、登録銘柄に関係するニュースを中心に表示。VIX・銘柄詳細・メモリ分析は閉じた詳細へ移動。
- 新規端末の固定監視リストを廃止。1銘柄を選ぶだけで開始でき、株数・取得単価は後から登録。日本語会社名・ひらがな・全角検索を主要企業の実在するlistingへ照合。
- メモリの詳細はMU/SKHY/SNDK等への登録上の関係がある場合に表示。既存のメモリ3社分析、テーマ29定義、Ranked/Thinは保持。
- 端末内に実際に取得した銘柄別観測を保存。同じデータの再読込では比較基準を動かさない。初回・追加直後・古い価格・取得失敗・通貨不一致では変化を出さない。
- ニュースは関連、初回、新着、要約更新、確認済みを区別。追跡URL・同一見出しを重複排除し、数値の異なる続報は保持。未取得本文を要約済みとしない。全件成功、一部失敗、失敗、未更新を区別。
- 資産は取得済み分を総額としない。古い代替価格経路のキャッシュとドル現金に必要な為替も品質判定へ反映。会計式と記録済み日付は変更しない。
- ライト／ダーク／端末設定。装飾を減らして文字・余白・色を統一。バックアップを設定上部へ移動し、JSON復元は銘柄マスタが取得できない時も検証済みの保存記録を復元可能。

## データ保持と境界

`mystockos.private.v6` と旧キーを維持。既存version 6に移行は不要。任意の `appearance` / `morningBrief` 以外の保有、口座、取得単価、判断enum、根拠、会計、履歴を保持する。旧version 2〜5の移行は既存処理を使用する。

公開API・GitHubへ個人データを送信しない。新しい比較観測もバックアップに含まれる。ニュース収集・要約は既存の公開企業情報の処理を使用する。Theme System v1.0の8凍結blob、Shadow処理、モデル昇格や売買接続には変更なし。

## 検証

- 変更前：Node 20テストファイル、Python 97件、8凍結blob、テーマ設定検証に合格。
- 変更前ブラウザ：ChromiumとWebKitで既存の操作、登録、円換算、現金、カレンダー、再読込、320/390/430/1024pxを検証。
- 変更後：Node 21テストファイル（新規11ケースを含む）、Python 97件、凍結blobに合格。
- ブラウザ：`mobile-smoke.mjs`、`mobile-brokerages.mjs`、`mobile-history.mjs`、`mobile-themes.mjs`、`mobile-morning.mjs` をChromium/WebKitで実行。
- 新導線：日本語検索、初回に監視だけで開始、前回価格の比較、ニュース重複と本文失敗、既存複数口座・配当・入出金の保持、JSON書出し・復元・不正ファイル・通信失敗中の復元、両表示モード、スマホ幅。
- 数字の文字切れと横スクロールを検査。実データや本人端末を使わず、独立ブラウザ内の架空データで実行。

ローカル環境ではChromium 153（公式npm配布パッケージ）とWebKit 26.0、Playwright 1.58.2を使用。CIはリポジトリ既存のPlaywright 1.62.1を使用する。

公開画面で見つけた、同一配信元・同日・引用の前置きだけが異なる発表の重複も排除。数値が異なる続報は保持する。ホームのニュース要約は110文字までとし、全文は詳細に残す。新規モジュールも含めてキャッシュ更新用のimport mapを統一する。

## 確認範囲

iPhone実機は操作していない。Safari相当のWebKitとスマートフォンviewportによる模擬確認。ニュース収集対象は既存の半導体関連公式配信元であり、全上場銘柄を網羅しない。配信元の取得失敗、対象外・未取得価格は画面で明示する。記録がない時点の保有や差分は生成しない。

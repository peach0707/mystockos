# ネイティブ横スクロールによるタブ切替

トップ5画面（ホーム・テーマ・銘柄・ニュース・保有）を、保持された `.tab-page` と横スクロール可能な `.tab-pager` に配置する。横移動は Safari の CSS Scroll Snap に任せる。

- `scroll-snap-type: x mandatory`、`scroll-snap-align: start`、`scroll-snap-stop: always`。
- 指の追従・慣性・方向判定・減速はブラウザが担当。touch イベント、独自の速度・距離判定、transform アニメーション、隣ページ複製は撤去。
- 各ページは独立したネイティブ縦スクロール領域。タブ切替では再描画せず DOM と縦位置を保持する。データ変更時のみ差分のあるページ本文を更新する。
- `scrollend` 完了時に現在ページを読む。非対応ブラウザはスクロールの idle 後に読む。どちらも位置を強制補正しない。
- ナビを押すとブラウザの `scrollTo` で目的タブへ移動する。画面幅が変わった場合のみ選択タブ位置を再整列し、Safariのバー開閉など高さだけの変更では動かさない。
- トップタブは `history.replaceState`。詳細のみ `pushState`。詳細表示中は pager を非表示とし、遅れて届いた scrollend を無視する。戻る操作で保持済みタブを復元する。
- ニュースの登録フォームは `#news/add` 子画面へ移動。既存の登録・検証処理は変更しない。
- ブラウザの端スワイプをイベントで奪わない。水平 overscroll は `auto` とし、Safari の戻る操作を抑制する contain/none を付けない。
- 主要5画面の横移動はネイティブスクロールなのでリンクのタップ抑制もブラウザに任せる。

## 検証

Node の pager テストはページ保持、位置復元、未完了スクロールの扱い、履歴分離、100回のタブ切替を検証する。これらはブラウザの物理挙動を検証するものではない。

iPhone Safari / ホーム画面からの standalone で、左右フリック、低速ドラッグ、斜め操作、テーマ行・銘柄行・カードからの開始、途中停止・反転、縦スクロールをそれぞれ10回確認する。詳細画面のブラウザ戻る、フォーム入力、画面回転、ナビの同期も確認する。

今回、ブラウザ接続が CDP タイムアウトしたため、実機合格・60fps は未確認。プレビューによる実機レビューが必要。

# iPhoneの追従型ページスワイプ

ホーム → テーマ → 銘柄 → ニュース → 保有。左で次、右で前へ移動。端では軽い抵抗を付けて戻り、循環しません。下部ナビも引き続き使えます。

## 描画と遷移

- touchstartで座標・画面幅を記録するだけ。5画面の生成はしません。
- 10px以上動き、横移動が縦の1.6倍を超えてから横ドラッグを開始。
- touchmoveは座標更新とrequestAnimationFrame予約だけ。1フレームに1回、translate3dで現在画面と隣画面を指に追従させます。moveループでレイアウト寸法を読みません。
- 隣の画面は方向確定後、必要な側だけ一度生成。反対へ引き戻した場合も各側1回まで。プレビューはinert・aria-hiddenで操作や読み上げの対象外。
- ドラッグ中はtransition:none。離した後のみ240msのtransform transitionで移動先または元の位置へスナップ。
- 確定条件：横移動が縦の1.8倍超、かつ距離がmax(72px,画面幅の25%)以上、または32px以上＋直近約100msの速度0.5px/ms以上。速さの方向は現在の移動方向と一致させます。止まってから離した操作は高速フリックとして扱いません。
- スナップ完了後にhashを変更し、既存ルーターでナビ・タイトル・フォーカスを同期。用意した隣画面のDOMを移し替え、同じ画面を再生成しません。
- will-change:transformは操作中の要素だけ。完了・中止で元のstyleへ戻し、隣画面・RAF・タイマーを片付けます。
- 「視差効果を減らす」では指への追従は維持し、離した後のアニメーションを省略。

## 誤操作防止

- 左右28pxの画面端はSafariの戻る・進む操作を優先。
- 縦・斜め方向と判定したら即解除。その指操作を横移動へ再解釈しません。
- touchstart/endはpassive。touchmoveだけnon-passiveとし、横ドラッグが確定した場合だけpreventDefaultします。touch-actionは制限せず、縦スクロール・複数指ズームを維持します。
- 入力・ボタン・リンク・フォーム・編集フォーカス・文字選択・横スクロール領域を除外。
- 親5画面のみ有効。テーマ詳細、銘柄詳細、損益カレンダー、設定等では無効。
- 任意の横操作領域は `data-page-swipe="off"` でも除外できます。
- 複数指、touchcancel、スクロール、リサイズ、pagehide、外部ナビ、データ更新やフォーム保存による再描画で中止。ドラッグ直後の誤クリックを抑制します。

## 検証範囲

Node回帰テストはRAFでの座標追従・隣画面生成回数・距離/速度判定・復帰・DOM再利用・ルーター同期タイミング・除外・中止・片付けを検証します。Safari/standaloneの設定を想定したテストは、実際のiOS WebKit・60fps測定の代替ではありません。

Safariとホーム画面からのstandalone起動で、以下を実機確認してください。

1. 本文中央をゆっくり左右へ動かし、離す前に現在画面と隣画面が追従する。
2. 短く引いて離すと戻る。十分な距離または短いフリックで移動し、収まった後にナビが切り替わる。
3. 指を止めてから離す、途中で方向を変える、連続スワイプでも引っ掛かりや空白が残らない。
4. 縦スクロール・画面端の戻る操作・入力・判断選択・根拠選択・カレンダーは誤動作しない。
5. 画面回転・バックグラウンド復帰・通常の下部ナビ操作でも残像がない。
6. スクロール途中からの移動、ホームバーと固定ナビ、「視差効果を減らす」を確認する。

# 日常操作・見やすさの改善（2026-10-13）

既存の株ゴリラを更新。iSPEEDの銘柄一覧・直接アクセスと、カビュウの資産推移・損益可視化を参考に、情報の優先順位と操作を整理した。

## 変更

- 下部ナビゲーションとスワイプ順を「ホーム・資産・銘柄・ニュース・分析」に統一。
- ホームにカレンダー、保有登録、監視銘柄、メモリ3社へのショートカットを配置。保有株または監視銘柄の株価変化を最大4銘柄表示。
- 資産画面にサマリー・保有一覧へのページ内移動を追加。保有カードを一覧/詳細で切替。
- 銘柄一覧は終値、前日比、実際に取得した終値推移を同じ列で比較。登録順、上昇率、下落率、銘柄名で並べ替え。検索語は並べ替え・データ更新でも維持。
- ニュースの絞り込みを上部へ移動。7日間の重要ニュースを開閉式にし、記事へ到達しやすくした。
- 目のボタンでサマリー、保有一覧、評価履歴の金額を表示/非表示。編集フォームは入力確認のため金額を表示する。スクリーンリーダー用のカレンダー金額も連動。
- 表示設定は `mystockos.display.v1` に端末内保存。保有などの既存データは `mystockos.private.v6` を継続。表示設定の保存失敗で個人データの読込を妨げない。

## 維持する仕様

既存の保有数量・取得単価・証券会社・複数口座の合算・配当・入出金・観測履歴・ニュースメモ・バックアップを保持。会計式、Theme System v1.0、29テーマの定義、Ranked/Thin、Shadow Modeを変更しない。価格は日足であり、リアルタイム株価や証券会社との自動連携を追加するものではない。新たな個人データの外部送信はない。

## 検証

Node 157ケース、Python 97ケース、8凍結blobとテーマ設定の検証に合格。ブラウザの受入確認は既存の5スイートと `mobile-usability.mjs` で行う。Chromium/WebKit、320/390/430/1024px、ライト/ダーク、保有編集・合算・履歴・復元・オフライン保持と、新しい検索/並べ替え/非表示/表示切替を対象とする。テスト口座は架空のデータ。タブ選択後のスクロール完了や画面幅変更で同じURLを再更新せず、WebKitの履歴更新制限に不要に達しないようにした。

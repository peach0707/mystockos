# 投資根拠タグ v1

投資根拠は銘柄単位の手動タグです。保有と監視の両方に登録しても共通の根拠を参照します。保有判断・監視判断の独立した固定enumは変更しません。自由記述欄は設けません。

|内部enum|表示|
|---|---|
|theme_growth|テーマ成長|
|earnings_growth|業績成長|
|undervaluation|割安|
|supply_demand|需給|
|technology_edge|技術優位|
|catalyst|カタリスト|
|market_share|市場シェア|
|policy_tailwind|政策追い風|

0〜5個を選択できます。保有登録・編集ではチェックボックス、登録済み銘柄の詳細では個別ON/OFFボタンを使用します。詳細の「維持中 N / 5件」は現在選択されているタグの数です。根拠が成立していることを自動検証した数ではありません。

5個選択中は未選択ボタンを無効化します。フォームの6個目は受け付けず、保存・バックアップ読込時にも最大数・重複・未知のenumを検証します。根拠タグによる点数計算や売買判断はありません。

## 保存と履歴
個人データは localStorage `mystockos.private.v5` のみ。JSONバックアップに含めます。
- rationaleSchemaVersion: 1
- rationales[ticker]: 有効なタグenumの配列（定義順）
- rationaleHistory[]: id、recorded_at（端末のUTC時刻）、ticker、security_id（取得済みなら市場を含むID）、contexts（変更時点のheld/watch）、before、after、added、removed、source: manual、enum_version: 1

変更があったときのみ履歴に追記し、順序だけの変更・同じ選択での再保存は重複しません。変更前後の配列は独立コピーです。OFFにしても過去イベントは残します。直近10件を詳細画面で表示し、全履歴をバックアップに含めます。旧いタグenumを別の意味に再利用しません。

## 移行と範囲
旧v4からv5へ移行します。v2/v3は既存移行を経由します。旧キーは保持し、新形式を検証して保存できた場合だけ切り替えます。容量不足・不正データでは旧データを保持して編集停止とします。

旧投資根拠の自由文章はバックアップ用に保持し、タグや日時を推測しません。タグ未選択・履歴なしで開始し、ユーザーが選択した時点から記録します。既存の判断enum・判断履歴・金融台帳を維持します。

手動履歴は将来の時点検証用であり、改ざん耐性や端末時計の正確性を保証するサーバー台帳ではありません。Forward Engine / Shadow Mode・予測・採点・本番シグナルは実装していません。Theme System v1.0のCatalystスコア除外等も変更しません。

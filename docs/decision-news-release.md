# 日次確認画面と半導体ニュース（2026-09-22）

## 利用の流れ

- ホームから「買い条件を見る」「保有を見直す」で銘柄へ移動する。
- 銘柄を開くと、確定日足の推移、購入前・保有中の確認条件、価格の節目、関連ニュースを読める。
- ニュースでは分野・自分の銘柄で絞り込み、直近7日間の影響をまとめて確認・コピーできる。
- 既存の保有、監視、判断、会計、ニュースメモは従来の端末内保存を使う。

## 更新

`briefing.yml` は公式RSSを3時間ごとに取得する。主要20銘柄の日足は米国平日の22:11 UTC（日本時間翌朝7:11）に収集し、翌日の04:11 UTC（13:11）に再確認する。GitHub Actionsの実行待ちによって遅れることがある。同じ取引日の80%以上を取得済みなら追加の価格API呼び出しを行わない。通常20クレジット以内、再取得時は1日最大40クレジットを追加で利用する。既存のTwelve Dataの認証を使用し、新しい有料契約は不要。

画面は表示中5分ごと、復帰・オンライン復帰時にも再取得する。更新操作は公開済みファイルの再取得であり、価格APIを利用者のブラウザから呼び出さない。入力中のフォームや検索は保持し、画面を切り替えた時に最新表示へ移る。クリップボードを使えない環境ではレポートをテキストファイルとして保存する。

## 判定の範囲

購入・保有の条件は、64営業日の確定終値から計算する20/50日平均、前日までの20日終値高値・安値、14日単純RSI、前20日平均との出来高比を利用する。予測・期待収益・売買推奨を算出するものではない。取引中の未確定日足を確定終値として扱わず、古い・欠損・キャッシュのみの分析は判定を保留する。自分で保存した売買判断の列挙値を変更しない。

ニュースは公式フィードの見出し、日付、出典を収集し、見出しに含まれる論点を日本語で整理する。影響・波及候補は条件付きの確認ポイントで、本文全体の翻訳・AI分析や価格方向の予測ではない。発表元、関連候補、事実、確認ポイントを分離する。重複見出し、未来日、90日より前のニュースを除き、直近7日の集計には未来日を含めない。

## 取得不足の扱い

初回の価格は19/20銘柄を取得。SKHYは必要な日足履歴不足のため保留。公式配信は8/9ソースを取得でき、Coherent IRは取得失敗を表示する。取得失敗を隠さず、以前の記事・価格は基準日を伴って保持する。ニュースは取得先の公式発表を対象とし、業界報道の全件網羅を保証しない。

- 公式RSSで記事を発見し、同じ公式配信元のHTTPS本文を取得。取得先を限定し、リダイレクトも検査する。
- 公開本文を更新サーバー内のQwen2.5-7B（Q4）で日本語2文に要約する。JSON形式、日本語、長さ、原文根拠、異常反復を検査する。条件付きの影響と確認点は既存分類の定型文であり、本文の事実と区別する。外部推論APIや秘密鍵に依存しない。
- 記事ごとに本文ハッシュ、要約モデル、確認時刻を記録。成功した要約は再利用し、失敗は要約待ちと明示する。45日以内の未処理記事を1回最大8件、メモリ配信元を優先。定期更新で順次処理する。

- VIXは今後30日の予想変動率で方向を示さない。区分はアプリ上の説明用目安。リアルタイム値とは区別する。
- 市場判定ジョブは別銘柄のHTTP429で停止していたため、VIX取得を独立させた。既存の計算式・固定済み更新処理と個人保有・履歴には変更なし。

# 日本語ニュース・メモリ・VIX

- 公式RSSで記事を発見し、同じ公式配信元のHTTPS本文を取得。取得先を限定し、リダイレクトも検査する。
- GitHub Modelsに公開記事だけを送り、日本語見出し・事実要約・条件付きの影響・次の確認点を生成する。本文根拠の抜粋を検証し、原文の転載は保存しない。保有情報は送信しない。
- 記事ごとに本文ハッシュ、要約モデル、確認時刻を記録。成功した要約は再利用し、失敗は要約待ちと明示する。45日以内の未処理記事を1回最大12件、メモリ配信元を優先。定期更新で順次処理する。
- Sandisk公式IRを収集先に追加。メモリのニュース絞り込みにはNANDのSNDKも含める。ホームにMU/SKHY/SNDKへの入口を追加。テーマ定義、順位、個人の監視登録を変更しない。
- VIX終値を市場判定から独立して約3時間ごとに更新。CboeとFREDの有効な最新日付を採用し、両方失敗しても保存値を消さない。日付・取得失敗・キャッシュを確認して現在の警戒表示を抑止する。
- VIXは今後30日の予想変動率で方向を示さない。区分はアプリ上の説明用目安。リアルタイム値とは区別する。
- 市場判定ジョブは別銘柄のHTTP429で停止していたため、VIX取得を独立させた。既存の計算式・固定済み更新処理と個人保有・履歴には変更なし。

検証：ニュース分類と本文根拠、取得失敗、未来日付、VIX鮮度、MU/SKHY/SNDK導線、既存保有の計算・移行テスト、Chromium/WebKitのスマホ表示。

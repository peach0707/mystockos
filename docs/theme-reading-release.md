# テーマを読む：状態・根拠・確認ポイント

2026-10-02。数値の一覧から、値動きの意味とデータの限界を読める画面へ変更。

## 画面

- 一覧カード：状態の文章、強さ・勢い・短期熱量、根拠、5日・21日価格リターン。
- 全テーマ／保有に関連／変化の兆し／注意点の切替。テーマ名・ティッカーの検索。
- 詳細：次に確認すること、基準日と取得元、有効銘柄数、計算対象外銘柄、構成銘柄、計算内訳。
- ホームと銘柄詳細も同じ説明を使用。未実装の将来スコア列は撤去。

## 誤読を防ぐ境界

- 「先行」は予測ではなく相対系列の位置・方向。「相対的に上向き」と表示。
- 熱量の点数だけで過熱とは判定しない。正式な hot / hot_eligible / single_stock_driven を区別。
- 未確認の状態切替は、前の状態・現在の候補・確認回数を区別する。
- データ不足は判断保留。少数構成・短期熱量・観察テーマは横断ランキングしない。
- 株価の基準日でテーマの鮮度を代用しない。古い日付・キャッシュ・将来日・営業日不明を表示で区別。
- データの充足度は予測精度ではない。「予測精度は未検証」を明示。勝率を生成しない。
- 保有との関連は登録済みティッカーと公式構成の照合だけ。ETFの間接保有を推定しない。
- 凍結された計算、テーマ構成、判断enum、個人データのキー・保存方式は変更しない。
